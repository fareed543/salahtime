## Versioning Convention

`MAJOR.MINOR.PATCH`

| Increment | When |
|---|---|
| `MAJOR` | Breaking change to a method or template that requires existing reports/docs to be reworked |
| `MINOR` | New method or template, new module onboarded, new SOCK entry, or an additive change that needs no rework |
| `PATCH` | Factual correction, typo fix or clarification that changes no rule |
