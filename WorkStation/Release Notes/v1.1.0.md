# Release Notes — v1.1.0 (2026-10-02)

Engineering Skills reorganised into two tracks, because the app is largely
built: **reverse engineering** to an as-built baseline, then **AI-driven
change requests / new features** against it.

## Added

- `Engineering Skills/Reverse-Engineering/RE-Method.md` — phases RE-0 … RE-6, when an as-built LLD is worth writing, module done criteria.
- `Engineering Skills/Change-Request/CR-Method.md` + `CR-Template.md` — CR/NF classification (S/M/L), 8-step lifecycle with design-approval gate, hidden-ripple checklist.
- `Engineering Skills/FDS/FDS-Method.md` + `FDS-Template.md` — as-built and delta modes, ID conventions per module.
- `Engineering Skills/HLD/HLD-Method.md` + `HLD-Template.md` — six hats mapped to SalahTime (H6 = Events & Native).
- `Engineering Skills/LLD/LLD-Method.md` + `Templates/` — Data, API, Service, Screen, Native.
- `Engineering Skills/Development/Development-Skill.md` — conventions observed in the code + verification checklist.
- `Product/Change Requests/README.md` — CR / NF register.

## Changed

- `CLAUDE.md` — describes the two-track workflow and the design-approval gate.
- `Engineering Skills/README.md` — full index with track diagram.
