## 1. Request

> Missing big cities: Ghaziabad, Noida, Thane, Mumbra, Bhiwandi, Murshidabad, Nellore, Hubballi and Kayalpattinam have no page. Oneindia's advantage is one page per district. — as we are following for city instead of district

## 2. Goal & Acceptance Criteria

**Goal:** every significant Indian city with a large Muslim population has its own prayer-times page; coverage is by city, not by district.

| # | Given / When / Then | Platform |
|---|---|---|
| AC-1 | Given the release, when `/prayer-times/india/ghaziabad` (and every city in §4 list A) is requested, then it returns 200 with "Prayer Times in Ghaziabad Today…" title, today's times in the description and the city's state | Web |
| AC-2 | Every list-A city is in `sitemap-cities.xml`, appears in "Prayer times in cities near …" of its neighbours (e.g. Noida on Ghaziabad, Mumbra on Thane) and in the `/prayer-times/india` directory | Web |
| AC-3 | Old spellings redirect to the one page: `/prayer-times/india/gurgaon` → `gurugram`, `hubli` → `hubballi`, `kayalpatnam` → `kayalpattinam` | Web |
| AC-4 | Each new city's Fajr and Maghrib differ by ≤ 2 minutes from IslamicFinder (Karachi, Hanafi) for the same date | Web |
| AC-5 | The cities can be found in the app's city search (Settings → Location, onboarding) | Web + Android (Android: next APK) |

**Out of scope:** district pages; the back-office location release (see Follow-ups); cities outside India.

## 4. Design Delta

**FDS:** City coverage rule — a city gets a page when it is a separate municipal city (not a district, not a neighbourhood of a listed city) with a notable Muslim population or ≥ 5 lakh people. Alternate spellings are redirects, never second pages.
