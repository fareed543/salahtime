## 1. Request

ST-00024: "Tinglish mean language should be in English. Tinglish will help new
genration to read telugu in English language. And report icons is in side
menu, can you keep it in top right before language section so the initial days
we can resolve the issues easily."

## 2. Goal & Acceptance Criteria

**Goal:** the Tinglish language shows Telugu written in English letters, and
Report Issue can be opened from the header.

| # | Given / When / Then | Platform |
|---|---|---|
| AC-1 | Given Tinglish (`te-latn`) is selected, every screen shows Telugu in Latin letters; no string in `te-latn.json` contains Telugu script. | Web + Android |
| AC-2 | `te-latn.json` has the same keys as `en.json` and the same `{{placeholders}}` per string as before. | Web + Android |
| AC-3 | The header shows a flag icon just before the language button; tapping it opens `/report-issue`. | Web + Android |
| AC-4 | The header still fits on a phone-width screen (no overflow or wrapping). | Web + Android |
| AC-5 | Same as AC-1/AC-2 for Hinglish (`hi-latn`, 843 Devanagari strings) — scope added 2026-11-02 at the user's request. | Web + Android |

**Out of scope:** side-menu Report Issue entry is kept; dua titles/content
come from `assets/data/duas.json`, not the i18n files.

## 3. Impact Analysis

- `frontend/src/assets/i18n/te-latn.json` — 844 of 1,195 strings were a copy
  of `te.json` (Telugu script); the rest were already Roman.
- `frontend/src/assets/i18n/hi-latn.json` — 843 of 1,195 strings in Devanagari.
- Language list unchanged: `frontend/src/app/services/translate.service.ts:26`,
  `api/models/Language.php:27`, `database/2026-10-12_app_languages.sql:32`.
- Header: `frontend/src/app/layouts/main-layout/main-layout.component.html:41`
  (header actions); existing styles `main-layout.component.scss:44`, `:255`
  apply to the new link. Label reuses `MENU.REPORT_ISSUE` (no new keys).
- Report Issue route/menu: `frontend/src/app/config/menu.config.ts:19` (kept).
- Ripple checklist: translations — only `te-latn` and `hi-latn`; no route/SEO, storage,
  notification channel, keep.xml, back-office or API change.

## 4. Design Delta

- Transliterate the 844 Telugu-script strings; English loanwords in normal
  English spelling, Islamic terms in their usual spelling (Fajr, Zuhr, Asr,
  Maghrib, Isha, Masjid, Azan…); placeholders and HTML untouched.
- Add `<a routerLink="/report-issue">` with `bi-flag` icon before the language
  button, `aria-label`/`title` = `MENU.REPORT_ISSUE`.

## 5. Implementation Plan

1. Extract Telugu-script strings, transliterate, merge back into `te-latn.json`.
2. Add the header link.
3. Validate JSON (no Telugu script, keys and placeholders match), production
   build, browser check desktop + phone width.
