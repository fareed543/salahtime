## 1. Request

> "We have built the compass, that works if the device has a compass. Can we show the Qibla direction
> even if there is no compass, like how Google Maps shows the directions? Let's analyze this."

Decisions taken on 2026-11-08: methods **map line + sun** (walking-heading and gyroscope modes later);
map provider **Google Maps, satellite**.

## 2. Goal & Acceptance Criteria

**Goal:** people whose device has no compass — phones without a magnetometer and every desktop/laptop
visitor — can still find the Qibla, by lining up a Qibla line on a satellite map of where they stand,
or by using the sun.

| # | Given / When / Then | Platform |
|---|---|---|
| AC-1 | Given location is available and no true-north reading arrives within 3 s, when the Qibla screen settles, then it shows the **Map** view: Google satellite map centred on the user, a "you" marker, and a Qibla line from the user toward the Kaaba, plus the bearing ("293° WNW") and distance to the Kaaba | Web + Android |
| AC-2 | Given the Map view, when the user pans/zooms, then the Qibla line stays a true great-circle line from the user's point toward Makkah, and a "re-centre" button brings the map back to the user | Web + Android |
| AC-3 | Given the sun is above the horizon, when the Map view (or the no-map fallback) is shown, then a **sun guide** says "Face the sun — the Qibla is N° to your left/right" (or "almost straight ahead/behind you") with a small diagram, computed for the current time and location | Web + Android |
| AC-4 | Given the sun is below the horizon, then the sun guide says so and the map + bearing remain | Web + Android |
| AC-5 | Given the map cannot load (offline, blocked, key or quota error), then no error popup: the screen shows the sun guide and the bearing text, as today, and a "Try map again" button | Web + Android |
| AC-6 | Given the device **has** a compass, then the compass works as today (no regression), and a **Compass / Map** switch lets the user check the direction on the map; the last choice is remembered | Web + Android |
| AC-7 | Given location is not available, then the screen behaves as today (location error + Retry), and the map is not loaded | Web + Android |
| AC-8 | The Google Maps script is loaded only when the Map view is opened — never on other pages, never in the initial bundle — and the prerendered `/qibla-direction` page is unchanged for crawlers | Web |

**Out of scope:** walk-a-few-steps (GPS course) heading, gyroscope tracking after alignment, moon guide,
map rotation (the map stays north-up), iOS app (no iOS project).

## 4. Design Delta

**FDS (Qibla rules, new):**
- **QB-1 View choice.** Two views: **Compass** (today's dial) and **Map**. Default: Compass when a
  true-north reading arrives; Map when none arrives within 3 s (existing detection). A user's explicit
  choice is saved and wins next time — except Compass is never forced on a device without a compass.
- **QB-2 Map view.** Google Maps, satellite (hybrid labels), north-up, centred on the user at street
  zoom. Markers: "you" and the Kaaba. A **geodesic** line from the user toward the Kaaba (the true Qibla
  path), drawn in the theme green. Header text: bearing ("293° WNW") and distance ("4,123 km to the
  Kaaba"). Help line: "Line up the green line with the streets or walls around you." Re-centre button.
- **QB-3 Sun guide.** Sun azimuth/altitude for now and the user's location (NOAA solar position).
  Above 0° altitude: relative angle = Qibla bearing − sun azimuth, shown as "Face the sun — the Qibla is
  N° to your right/left"; within ±10° "almost straight ahead"; within ±10° of 180° "almost straight
  behind you". Below the horizon: "The sun has set — use the map or the bearing." Refreshes each minute.
- **QB-4 Map failure.** Any load error (offline, script blocked, key/referrer error, quota) shows the
  sun guide + bearing + "Try map again". No popup.
- **QB-5 Load on demand.** The Maps script loads only when the Map view is first shown, once per visit.

**HLD:**
- *UI hat:* Compass / Map switch (segmented buttons) under the header; Map view = `QiblaMapComponent`
  (`@Input` user position, Kaaba bearing); sun guide card shared by Map view and fallback.
- *Process hat:* `GoogleMapsLoaderService.load()` → injects `https://maps.googleapis.com/maps/api/js`
  (async, `key` from `environment.googleMapsApiKey`, `libraries=geometry`) → resolves when
  `google.maps` is ready; errors (incl. `gm_authFailure`) reject → QB-4.
- *Rules hat:* QB-1 … QB-5. Sun maths is a pure function with unit tests.
- *Config hat:* browser key on a Google Cloud project with billing; restrict to **Maps JavaScript API**
  and referrers `https://salah-times.in/*`, `https://localhost/*` (Android app WebView),
  `http://localhost:4200/*` (dev). Key added to the environment files by the owner.
- *Native hat:* none; works in the Capacitor WebView with internet.

**LLD:** none separate — the units are small; specs are in §5.
